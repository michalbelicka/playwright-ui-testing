# Test Plan

## Project Overview

UI testing project using Playwright and Python on the Automation Exercise e-commerce website.

## Testing Approach

The website will first be explored and tested manually to understand its main functionality and identify relevant test scenarios.

The main scenarios will include:

- User registration
- User login and logout
- Product browsing and product details
- Adding products to the shopping cart
- Removing products from the shopping cart
- Updating product quantity
- Checkout process
- Basic form validation and negative scenarios

After the manual testing phase, selected scenarios will be automated using Playwright.

## Goal

The goal is to practice UI test automation on a realistic e-commerce website and gradually build a maintainable Playwright test suite.
